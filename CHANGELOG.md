## [0.1.0] - 2026-08-26

### Added

- Windows tray status for Claude, Codex, and Ollama.
- Usage-window details in a tray popup and optional always-on-top overlay.
- Configurable warning and critical thresholds with desktop notifications.
- Global overlay shortcut and optional start with Windows.
- Sanitized local settings and bounded runtime logging under `%APPDATA%\QuotaGlass`.
- Automated build, test, secret-scan, and single-file Windows x64 publishing checks.
